## Three-Line Description

Real-Time Streaming Analytics System is a production-style cybersecurity analytics platform built as a Docker Compose microservices monorepo. It streams synthetic telemetry through Kafka and Spark, performs ML anomaly detection, generates SOC alerts/incidents, enriches events with local threat intelligence, and exposes a polished React XDR dashboard. The platform includes PostgreSQL, Elasticsearch, Prometheus, Grafana, FastAPI APIs, WebSockets, and developer-ready scripts/docs.
